# rclone Google Drive Client

This application is a personal utility used with [rclone](https://rclone.org/) to provide authenticated access to Google Drive.

## What does this application do?

This application uses the Google Drive API to allow rclone to access files stored in my Google Drive account.

It is used for personal file synchronisation and management between my devices. The application does not provide a public service and is not intended for use by other users.

## Google Drive access

When authorised, the application requests access to Google Drive so that rclone can perform the file operations required for synchronisation.

Authentication is handled by Google's OAuth 2.0 system. Google account credentials are not collected or stored by this application.

## Data handling

Google Drive data accessed through this application is used solely for personal file management and synchronisation.

The application does not sell, share, or use Google Drive data for advertising or unrelated purposes.

For more information about how data is handled, please see the [Privacy Policy](privacy).
